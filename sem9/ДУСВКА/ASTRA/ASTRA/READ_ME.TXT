   Версия 1:14 (февpаль 1995) программного комплекса ASTRA.4/pc по сравнению
 с предыдущими претерпела следующие изменения:

   - для каждого нового состава рабочего тела на экран дисплея и в файл 
     на диск выводится его брутто-формула; при выводе на печать приведенная
     к 1 кг формула не выводится, т.к. она и без того может быть надена среди
     преобразованных исходных данных (см. Содержание элементов [моль/кг])
     
   - при вычислениях параметров равновесия двухкомпонентных составов (окис-
     литель-горючее) на экран, в файл и на печать выводится вычисленное
     теоретическое (стехиометрическое) соотношение компонентов  
     
   - в исходные данные может быть добавлено ключевое слово EPS=, которое
     позволяет управлять выводом информации о равновесном составе; при наличии
     директивы <PrDom значение EPS - предельное значение для вывода
     концентраций веществ на экран, диск или печатающее устройство; по умол-
     чанию предполагается EPS=0.00001 моль/кг; Ключевое слово "не работает"
     при использовании директивы <PrFull.
     
   - ход расчетов может быть в любой момент прерван с выходом в точку
     задания (корректировки) исходных данных; для этого достаточно нажать
     клавишу End; напомним, что Ctrl-End снимает полностью выполнение   
     задания и обеспечивает возврат в DOS.
     
   - в базе данных уточнены термохимические постоянные газообразных веществ
     CN2 и N2C (изомеры)     

   Версия 1:15 (февраль 1996) 

   - исправлены ошибки при организации вывода на экран и в файл по 
     директиве <PrFull. Ошибки возникали при редкой и сложной комбинации 
     исходных данных.

   - обнаружено отсутствие в базе данных свойств AlO и SiO. 
     Данные восстановлены.

   Версия 1:16 (декабрь 1996) 

   - при выводе на экран брутто-формулы рабочего тела В.Л.Климовым обнаружена 
     ошибка. Если брутто-формула слишком длинна и не помещается на двух 
     строчках, то происходит программное прерывание. Исправлено, добавлена 
     возможность вывода в четыре строки.
   
   - из англоязычной версии перенесена возможность задавать до 50-ти значений
     любого из термодинамических параметров (при выводе на принтер в форматке
     печатаются только первые десять значений).

   - вывод числовых величин организован в естественном формате (с десятичной 
     точкой) вместо прежней экспоненциальной формы, существовавшей еще со
     времен ЕС ЭВМ.   

   - специально по просьбе В.Л.Климова введена новая директива <PrG для 
     вывода концентраций всех веществ (газообразных и конденсированных) в
     массовых долях.  

   Версия 1:17 (февраль 1997)

   - в этом варианте программы по просьбе проф. Бондаренко Б.И. (Институт
     газа НАН Украины, Киев) предусмотрены две дополнительные возможности:

      1. При задании исходного состава с помощью долей (частей) простых 
     веществ есть возможность задавать не массовые, а мольные (объемные 
     части веществ. Для этого в качестве разделителя между числом и формулой
     внутри круглых скобок нужно использовать символ #.
       Например:
                   p=0.1,T=1400,1600,(20#C1H4),(40#C1O),(5#H2O);

      2. Предусмотрена возможность задания "сухого" состава исходной газовой
     смеси. Для этого в исходные данные необходимо ввести:
           а) директиву  <DRY
           б) задавать величину мольного отношения водорода к углероду
              в исходном составе, используя для этого идентификатор H/C=
           в) "сухой" состав газа задавать в мольных (объемных) долях,
              используя разделитель # (см. п.1)
       Например:
                    <DRY>
                  p=0.1,  T=1500,  H/C=2, (25#C1O), (75#C1H2);    

   - исправлена ошибка, существовавшая с момента создания самого первого
     варианта программы: когда в списке параметров равновесия задавалось два
     одинаковых подряд идущих значения, то расчет выполнялся для этой 
     величины раз за разом, без конца (происходило зацикливание). 
     Удивительно, но об этой ошибке никто из пользователей раньше не сообщал. 
     Теперь все в порядке.
